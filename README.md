# GEPIA — projects overview

**GEPIA — Grupo Estudiantil de Proyectos de Ingeniería Aplicada.**

The primary objective of this student group is the development of engineering projects: from their initial conception through to their implementation and/or commercialization.

## How to start

Check the repository in <https://github.com/gepia-mgmt/gepia-repo-template> , so you can create a repository using this template, and follow the instructions in the README.
